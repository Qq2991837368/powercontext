PaperLens

把文献检索变成可追溯的证据包

PaperLens 是一个面向科研阅读的本地证据检索助手：导入论文摘要语料，用 seekdb 混合检索找到证据，用 PowerContext 记住研究判断。

找不到出处

结论听起来合理，却无法定位到论文里的具体句子和上下文。

覆盖不全

只搜关键词容易漏掉同义表述，单篇精读又难以覆盖整个语料库。

读完就忘

研究中的取舍和排除条件散落在笔记里，下次检索又要重新判断。

        技术边界

        • 01

          演示语料是作者整理的中文摘要，并非论文原文。

        • 02

          向量是 384 维确定性哈希，不是语义模型，因此检索显式放宽了准入阈值。

        • 03

          站点数据由本地 Python 核心离线预计算，站点本身不运行 seekdb。
